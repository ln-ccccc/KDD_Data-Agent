+# KDD Cup Data Agent Optimization Spec
+
+## Why
+当前项目结构已经具备了一个基于 LangGraph 的高级 Data Agent 雏形（包含 React 和 Plan-Execute 模式、工具集、上下文压缩等核心模块）。为了在 KDD Cup 中取得高分，我们需要针对比赛的特点（如：超大 Schema、复杂 SQL/Python 逻辑、严格的准确率要求和 Token 限制）对现有架构进行深度优化和增强。
+
+## What Changes
+**当前结构分析**：
+- `agents/` & `orchestrators/`：已支持 React 和 Plan & Execute 双模式，这是处理复杂数据任务的良好基础。
+- `runtime/` (包含 context_compression, recall)：已具备处理长上下文的中间件机制，对 KDD Cup 极为关键。
+- `tools/`：内置了 DuckDB, SQLite, Python 执行环境。
+- `benchmark/`：具备基础的评测框架雏形。
+
+**提分向优化点 (Changes)**：
+- [x] **架构评估**：完成现有基础架构的梳理。
+- [ ] **增强 Context Management (上下文管理)**：优化 `context_compression.py`，针对超大数据库 Schema 进行智能截断和摘要提取；增强 `recall_provider.py` 以实现更精准的 Schema 检索 (RAG)。
+- [ ] **增强 Tooling (工具链)**：在 `tools/` 中引入更高级的数据探索(EDA)工具，帮助 Agent 更好地理解数据分布。
+- [ ] **引入 Reflection & Self-Correction (反思与自纠错)**：在 `agents/` 或 LangGraph 图中增加严格的执行错误反思节点，提升代码/SQL一次性通过率。
+- [ ] **KDD Cup 专属 Benchmark 对齐**：优化 `benchmark/` 以完全对齐 KDD Cup 的打分逻辑（如执行准确率、结果比对），支持快速本地迭代打分。
+
+## Impact
+- Affected specs: Data Retrieval, Code Execution, Agent Reasoning, Evaluation.
+- Affected code:
+  - `src/data_agent_baseline/runtime/*`
+  - `src/data_agent_baseline/tools/*`
+  - `src/data_agent_baseline/orchestrators/*`
+  - `src/data_agent_baseline/benchmark/*`
+
+## ADDED Requirements
+### Requirement: 智能 Schema RAG 与上下文压缩
+The system SHALL provide 针对超大数据库的 Schema 检索能力，确保 Prompt 中只包含与当前 Query 相关的表结构，避免 Token 溢出，同时必须保证 `context_compression` 能有效处理过长的执行返回结果。
+
+### Requirement: 执行错误反思与重试机制
+The system SHALL provide 在 Python/SQL 执行报错时，自动将错误信息和 Traceback 反馈给 LLM 进行代码修正的能力，并具备严格的重试次数限制以防止死循环。
+
+### Requirement: 高效的本地评估闭环
+The system SHALL provide 完全模拟 KDD Cup 官方评分标准的本地 Benchmark 脚本，支持批量并发测试和错误案例归档，以指导进一步的 Prompt 优化。

+def _normalize_dataframe(df: pd.DataFrame) -> pd.DataFrame:
+    """Normalize dataframe for comparison."""
+    # Convert column names to lowercase and strip
+    df.columns = [str(c).lower().strip() for c in df.columns]
+    
+    # Sort columns alphabetically
+    df = df[sorted(df.columns)]
+    
+    # Trim whitespace from string columns and handle empty strings
+    for col in df.columns:
+        if df[col].dtype == "object":
+            try:
+                df[col] = df[col].str.strip()
+                df[col] = df[col].replace("", np.nan)
+            except Exception:
+                pass
+
+    # Sort rows by all columns
+    try:
+        df = df.sort_values(by=list(df.columns)).reset_index(drop=True)
+    except Exception as e:
+        logger.debug(f"Failed to sort dataframe: {e}")
+    return df
+
+def compare_dataframes(pred_df: pd.DataFrame, gold_df: pd.DataFrame) -> bool:
+    """
+    Compare two dataframes. Returns True if they match.
+    Matches ignore column/row order and use a float tolerance.
+    """
+    if pred_df.shape != gold_df.shape:
+        return False
+        
+    pred_df = _normalize_dataframe(pred_df)
+    gold_df = _normalize_dataframe(gold_df)
+    
+    if list(pred_df.columns) != list(gold_df.columns):
+        return False
+        
+    try:
+        pd.testing.assert_frame_equal(
+            pred_df, 
+            gold_df, 
+            check_dtype=False,
+            check_column_type=False,
+            check_exact=False,
+            atol=1e-5,
+            rtol=1e-5
+        )
+        return True
+    except AssertionError:
+        return False
+
+def evaluate_run(run_dir: Path, gold_dir: Path, output_report: Path | None = None) -> dict:
+    """
+    Evaluate a complete run against the gold dataset.
+    Returns a dictionary with evaluation results.
+    """
+    summary_path = run_dir / "summary.json"
+    if not summary_path.exists():
+        raise FileNotFoundError(f"Missing summary.json in {run_dir}")
+        
+    with open(summary_path, "r", encoding="utf-8") as f:
+        summary = json.load(f)
+        
+    tasks = summary.get("tasks", [])
+    
+    results = []
+    correct_count = 0
+    total_count = len(tasks)
+    
+    for task in tasks:
+        task_id = task["task_id"]
+        pred_csv = run_dir / task_id / "prediction.csv"
+        gold_csv = gold_dir / task_id / "gold.csv"
+        
+        status = "Failed"
+        reason = ""
+        is_correct = False
+        
+        if not task.get("succeeded", False):
+            status = "Execution Error"
+            reason = task.get("failure_reason", "Unknown error")
+        elif not pred_csv.exists():
+            status = "Missing Prediction"
+            reason = "prediction.csv not found"
+        elif not gold_csv.exists():
+            status = "Missing Gold"
+            reason = "gold.csv not found in dataset"
+        else:
+            try:
+                pred_df = pd.read_csv(pred_csv)
+                gold_df = pd.read_csv(gold_csv)
+                if compare_dataframes(pred_df, gold_df):
+                    is_correct = True
+                    status = "Correct"
+                    correct_count += 1
+                else:
+                    status = "Wrong Answer"
+                    reason = "Data mismatch"
+            except Exception as e:
+                status = "Evaluation Error"
+                reason = str(e)
+                
+        results.append({
+            "task_id": task_id,
+            "status": status,
+            "reason": reason,
+            "is_correct": is_correct
+        })
+        
+    pass_rate = correct_count / total_count if total_count > 0 else 0.0
+    
+    report = {
+        "run_id": summary.get("run_id", "unknown"),
+        "total_tasks": total_count,
+        "correct_tasks": correct_count,
+        "pass_rate": pass_rate,
+        "results": results
+    }
+    
+    if output_report:
+        with open(output_report, "w", encoding="utf-8") as f:
+            json.dump(report, f, indent=2, ensure_ascii=False)
+            
+    return report
+

+def extract_dataframe_stats(task: PublicTask, relative_path: str) -> dict[str, Any]:
+    """
+    Extract statistical information from a data file (CSV, Parquet, JSON, Excel).
+    Returns basic info like row/column count, head, describe(), missing values, etc.
+    """
+    path = resolve_context_path(task, relative_path)
+    ext = path.suffix.lower()
+    
+    try:
+        # For EDA, we might want to sample if the file is too large
+        # But reading the whole file might be needed for describe()
+        # To avoid OOM, let's try to read it normally, but limit rows for CSV/Excel
+        if ext == ".csv":
+            df = pd.read_csv(path, nrows=100000)
+        elif ext == ".parquet":
+            df = pd.read_parquet(path)
+        elif ext in [".json", ".jsonl"]:
+            df = pd.read_json(path, lines=(ext == ".jsonl"))
+        elif ext in [".xlsx", ".xls"]:
+            df = pd.read_excel(path, nrows=100000)
+        else:
+            return {"error": f"Unsupported file format for EDA: {ext}", "success": False}
+            
+        # Basic info
+        buf = io.StringIO()
+        df.info(buf=buf)
+        info_str = buf.getvalue()
+        
+        # Missing values
+        missing_values = df.isnull().sum().to_dict()
+        
+        # Describe
+        describe_df = df.describe(include='all')
+        describe_dict = describe_df.replace({np.nan: None}).to_dict()
+        
+        # Head
+        head_dict = df.head(5).replace({np.nan: None}).to_dict(orient="records")
+        
+        return {
+            "path": relative_path,
+            "row_count": len(df),
+            "column_count": len(df.columns),
+            "columns": list(df.columns),
+            "info": info_str,
+            "missing_values": missing_values,
+            "describe": describe_dict,
+            "head": head_dict,
+            "success": True
+        }
+    except Exception as e:
+        return {"error": str(e), "success": False}
